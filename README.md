# HELPABNTCCMN — Site de Infográficos

Versão 2.0 — foco nos infográficos, sem gerador de referências.

## Conteúdo
- Estrutura do trabalho acadêmico
- Formato e margens
- Paginação
- Indicativos de seções
- Tabelas, quadros e figuras
- Ilustrações
- Equações e fórmulas
- Siglas
- Cartaz de lançamento

## Publicação
O site é estático e pode ser publicado gratuitamente no GitHub Pages.

1. Crie um repositório no GitHub (por exemplo: `helpabntccmn`).
2. Envie todos os arquivos e a pasta `img`.
3. Em Settings → Pages, selecione a branch `main` e a pasta `/ (root)`.
4. Salve. O GitHub Pages fornecerá o endereço público.

## Observação
Os textos dos infográficos foram preservados como material visual enviado pela autora. O site não substitui a consulta às normas ABNT e às orientações institucionais.
